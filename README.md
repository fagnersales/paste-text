# paste-text

Tiny single-file web app: paste an image, drop a caption, drag it anywhere, copy or download the result.

Live: https://fagnersales.github.io/paste-text/

## Use

1. Open the page.
2. `Ctrl+V` to paste an image (or drag-drop a file).
3. Type a caption, tweak size / color / stroke / font.
4. Drag the text on the canvas to position.
5. **Copy Image** to clipboard or **Download PNG**.

## Stack

One `index.html`. No build, no deps. Plain Canvas 2D + Clipboard API.
